# ロケハンメモ

写真・動画撮影のロケハン（撮影前の下見）で見たことを、その場で記録するためのメモアプリです。単一HTMLファイル（`index.html`）で動作し、ログインもサーバーも不要です。

- **アプリ（公開URL）: https://hanaphoto.github.io/rokehan-memo/**
- **使い方ページ: https://hanaphoto.github.io/rokehan-memo/manual.html**（アプリ下部からも開けます）

フォトグラファーの方ならどなたでも、この公開URLからそのまま使えます。

## 説明書

### 基本の流れ

1. 公開URLをスマホのブラウザで開く
2. 現地で各セクションを開いて入力する（入力のたびに自動保存されます）
3. 最後に「結論・総合判定」を付ける
4. 「テキスト出力」または「CSV出力」でメモを書き出して保存・共有する
5. 次のロケハンに行く前に「全てリセット」で空に戻す

### 保存について（大事な注意）

- 入力内容は**お使いの端末のブラウザ内（localStorage）にだけ**保存されます。外部のサーバーには送信されません
- 保存されるのは**1件分だけ**です。別の場所のメモを始める前に、必ずテキスト／CSVで書き出してからリセットしてください
- 端末やブラウザが変わると内容は引き継がれません。ブラウザのデータを消去したり、プライベートブラウズで使ったりすると消えます
- 大切なメモは、ロケハンが終わったらその日のうちに書き出しておくのがおすすめです

### 画面のボタン

- **テキスト出力**：見出し付きの読みやすいテキストでプレビュー表示。コピーと `.txt` ダウンロードができます（ファイル名は「ロケハン_場所名_ロケハン日.txt」）
- **CSV出力**：項目名と内容の2列で書き出します。UTF-8（BOM付き）なのでExcelでそのまま開けます
- **全てリセット**：入力を全て消します（確認ダイアログあり）。書き出し忘れに注意してください

### 入力セクション（全16）

1. **結論・総合判定**：本番可／条件付き可／要再訪／不可、向いている撮影、おすすめの時間帯・季節、一言メモ
2. **基本情報**：場所名、ロケハン日、住所、マップURL、室内・室外、カテゴリ、利用時間、料金、天気、日の出・日没など
3. **アクセス・駐車場**：台数・料金・満車リスク、代替駐車場、最寄駅、荷物の運搬
4. **施設・設備**：トイレ、更衣、電源、水道、電波など（有／無／未確認＋メモ）
5. **撮影許可・ルール**：許可・申請、商用利用、コスプレ、三脚・ストロボ・ドローンの可否など
6. **光のメモ**：太陽の向き、順光・逆光の時間帯、夕景・夜景、室内の光
7. **スポット別メモ**：場所ごとのメモを何件でも追加できます
8. **撮影設定メモ**：テスト撮影の設定（カメラ・レンズ・絞り・SS・ISO・WBなど）を表で記録
9. **写真メモ**：写真そのものではなく、撮った写真についての文字メモ
10. **動画メモ**：動画のリンクURLと内容メモ
11. **音・環境**：騒音、風、虫、危険な場所、混雑する時間帯
12. **本番当日に向けたメモ**：集合場所、動線、雨天時、持っていく機材
13. **注意事項**
14. **要確認・次回見ること**：チェック付きのToDoリスト
15. **振り返り**：良かった点、気になった点、次回撮りたいもの
16. **現地チェックリスト**：現地で最低限見るべき7項目の進捗確認

分からない項目は、推測で埋めず空欄のままにして「要確認・次回見ること」に入れておくのがおすすめです。

### よくある質問

- **料金はかかりますか？** かかりません。公開URLを開くだけで使えます
- **入力した内容が他人に見られることはありますか？** ありません。内容は自分の端末のブラウザ内にだけ保存され、どこにも送信されません。ただし端末自体を共有している場合は、その端末でアプリを開いた人に見えるので注意してください
- **写真を添付できますか？** できません。写真は手元のカメラ・スマホで撮り、このアプリには文字メモだけを残す設計です
- **複数の場所を同時に保存できますか？** アプリ内では1件分だけです。場所ごとにテキスト／CSVで書き出して管理してください
- **オフラインで使えますか？** 一度開いた後は、電波の弱い場所でも入力できます（保存も端末内です）

## 公開前の確認について

このアプリは、外部の方が使う前提で公開前に中身を確認しています（2026-11-17）。

- 個人名・連絡先・特定の地名や住所など、個人に関わる初期データは入っていません（入力欄は全て空で、項目名だけの汎用設計です）
- 外部通信の仕組み（fetch、XMLHttpRequest等）は無く、入力内容が送信されることはありません
- 外部サイトのファイル（フォント・ライブラリ・画像など）の読み込みも無く、単一HTMLだけで完結します
- 保存はブラウザのlocalStorageだけです
